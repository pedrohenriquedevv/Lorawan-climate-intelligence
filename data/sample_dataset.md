# Dataset Description

## Source

Historical meteorological datasets collected from INMET stations.

## Variables

- Temperature
- Relative Humidity
- Rainfall
- Solar Radiation
- Wind Speed
- Timestamp

## Processing

The original datasets were processed through:

- ETL procedures
- Missing value treatment
- Linear interpolation
- Anomaly filtering
- Scientific discretization

## Note

Original research datasets are not publicly distributed in this repository.
