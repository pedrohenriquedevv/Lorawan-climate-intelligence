# Climate Intelligence Pipeline for LoRaWAN Networks

Data Engineering and Data Mining project developed for climate pattern discovery and Edge Computing decision support in LoRaWAN-based IoT networks.

---

## Project Overview

This project was developed as part of a Scientific Research Initiative (IC) focused on intelligent environmental monitoring systems for remote regions.

The objective was to discover climate patterns from historical meteorological datasets and transform them into actionable Edge Computing rules for LoRaWAN sensor networks.

---

## Research Context

The project is part of a research initiative involving:

- LoRaWAN Networks
- Mesh Topologies
- Environmental Monitoring
- Edge Computing
- Climate Intelligence

The proposed approach reduces unnecessary sensor transmissions while improving responsiveness during critical environmental conditions.
